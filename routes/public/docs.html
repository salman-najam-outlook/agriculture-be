Dimitra Public Registration API

Documentation for the public registration endpoint

POST /api/public/register

This endpoint handles the registration of new users and organizations in the Dimitra system.

Request

Headers

Content-Type: application/json

Request Body

{
  "firstName": "John",
  "lastName": "Doe",
  "phoneNumber": "+6281234567890",
  "email": "john@example.com",
  "country": "Indonesia",
  "organizationName": "My Cooperative",
  "organizationLogo": "https://your-aws-bucket.s3.amazonaws.com/logo.jpg",
  "products": ["Coffee", "Cacao"],
  "NoOfFarmsPlanningtoonboard": 5,
  "securityToken": "dimitra_public_reg_2025_secure_token_123456789"
}

Fields

Field Type Description Required
firstName string User's first name No
lastName string User's last name No
email string User's email address Yes
organizationName string Name of the organization Yes
products array Products interested in (Must include at least one of: "Coffee", "Cacao") Yes
securityToken string Security token for API access Yes
phoneNumber string User's phone number No
country string User's country (defaults to "Indonesia") No
organizationLogo string AWS S3 URL of the organization logo No
NoOfFarmsPlanningtoonboard integer Number of farms to onboard No

Response

Success Response (200)

{
  "success": true,
  "code": 200,
  "message": "Registration successful. Your default password is: "+defaultPassword +". Please change your password after login.",
  "data": {
    "id": "user-123",
    "email": "john@example.com",
    "firstName": "John",
    "lastName": "Doe",
    "organization": "org-123",
    "organizationCode": "my_cooperative",
    "organizationLogo": "https://your-aws-bucket.s3.amazonaws.com/logo.jpg",
    "NoOfFarmsPlanningtoonboard": 5
  }
}

Error Responses

Invalid Security Token (400)

{
  "success": false,
  "code": 400,
  "message": "Invalid security token"
}

Email Already Registered (400)

{
  "success": false,
  "code": 400,
  "message": "Email already registered"
}

Parent Organization not found (400)

{
  "success": false,
  "code": 400,
  "message": "Parent Organization not found"
}

Important Notes

  • The system automatically creates a default password for new users and Default Password is Dimitra@123
